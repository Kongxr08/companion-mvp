# 沙季：云端账号版

此目录保留曾上线的云端版本完整源码。**旧线上站点和云端数据已按要求永久删除，目前没有部署中的云端服务。** 源码不包含聊天记录、长期记忆数据库、账号密码或模型密钥。

该版本原先使用 Sites 私有托管、ChatGPT 账号登录与 Cloudflare D1 持久存储。下文描述它的实现能力，不表示现有在线服务，也不包含独立邮箱密码登录。

## 实现与数据

- 保留沙季 v2 人格，配色与本地版同步为象牙白、樱花粉、蜜桃金与紫罗兰的“樱色信笺”。
- 登录由 Sites 托管。应用不保存密码，也不自行实现 OAuth；服务端通过随请求注入的可信身份确认用户。
- 全部聊天、记忆、提醒和设置读写都以服务端用户 ID 为条件，不信任客户端传来的用户 ID。接口无登录返回401；跨站写入返回403。
- D1是持久数据库，聊天不会只留在手机缓存或运行进程内。不同设备刷新后同步，页面显示最近200条，导出包含完整记录。
- 每个写入批次校验资料版本；多个设备竞争写入时返回可重试的409，不静默覆盖。聊天请求 ID 去重，模型失败不写入半条记录。
- “导出我的数据”下载账号备份。保留副本有助于意外恢复；当前未另建定期异地备份任务，不承诺无限存储或永不丢失。

## 导入旧版

在旧版页面点击“导出我的数据”，再到云端“设定→导入本地备份”，选择JSON文件。只允许空账号导入，以免覆盖云端已有资料。导入一次性原子提交，重新关联消息和记忆来源，保留设置与提醒。文件上限2MB，单次至多10000条消息、2000条记忆和1000个提醒；过大的单项数据会在写入前拒绝。

不要把私人的导出文件或数据库放进Git仓库。云端不会自行扫描或上传电脑上的其他文件。

## 当前模型与提醒行为

按用户选择，本次先上线演示模式，之后再接真实模型。演示模板能测试聊天保存、记忆、情绪、提醒，但不是自由对话模型。

未来在站点的服务器环境变量中设置 `LLM_MODEL`、`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_API_STYLE`。密钥应标为secret，不放在浏览器或源码。支持 Responses 和兼容 Chat Completions 的HTTPS接口，真实模型会收到近期对话、相关记忆与人格背景。

云端采用按需运行：页面在线时每10秒检查资料和到期提醒，离线时下次打开补发。主动闲聊默认关闭，开启后使用简短模板并遵守每日上限与免打扰。**没有配置独立云端定时器、邮件或手机离线推送**；不要将“电脑关机后仍能访问”误解为“手机网页关闭后仍能收到系统推送”。

## 源码位置与验证

- `app/route.ts`：登录检查和聊天页面。
- `app/api/[...path]/route.ts`：每次请求验证账号身份。
- `lib/engine.mjs`：账号数据、对话、记忆、提醒、导入导出、版本冲突处理。
- `lib/http.mjs`：同源校验、请求大小限制及无敏感数据的错误响应。
- `lib/persona.mjs`：从本地版本保留的人格和默认设置。
- `db/schema.ts`、`drizzle/`：D1结构和不可变迁移。
- `public/`：保留并适配的页面样式和浏览器脚本。

运行 `node --test tests/engine.test.mjs`：24项测试覆盖账号隔离、持久保存、并发冲突、重试去重、事务回滚、导入重关联、匿名与跨站拒绝，以及模型失败不泄露响应。测试用Node SQLite执行实际迁移和相同SQL；D1本地模拟器和浏览器另做集成检查。

本地开发使用官方starter的 `npm run dev`；便携开发环境仅在loopback模拟测试账号，生产构建不包含模拟登录。`.openai/hosting.json` 是已删除站点的历史绑定配置，不是有效部署入口；本次仅归档源码，不创建或恢复站点。
